# 学习工作台优化

基线：`2832c5c`（v1.2.0-beta.3）。所有工作在本地功能分支进行，按可审查阶段提交。

## 实施与验收

1. 教学语义：特征候选向量与真实时间轴、行列式操作前后动画/当前与目标读数、SVD模式说明。关键帧与退化情况回归。
2. 学习与视觉：入门/自由实验、七场景问题引导、三个可判定的短实验、可折叠高级参数、移动画布与操作同屏、精度与图例。
3. 实验工作流：撤销重做、命名快照、版本化分享/导入导出、携带实际映射跨模块、教学图卡。恶意或不兼容输入不能破坏当前实验。
4. 连接概念：Ax=b与最小二乘（现有1–3维实矩阵范围），显示精确/不唯一/最小二乘和残差几何。
5. 整体审查：格式、类型、Lint、单测、生产构建、桌面与移动E2E；核查共享状态、数学对象和布局。记录实际结果。

## Git与审查规则

- 每阶段提交前检查`git diff --check`和具体差异，并运行相关测试。
- 保留已有测试契约；确实改变的产品行为更新相应测试，并新增语义断言。
- 不把临时截图、脚本、依赖或产物提交到源码；不自动推送或部署。
- 优化继续保留全部自由实验能力，课程不是强制访问门槛。
- 变更审查工具中的知识图谱能力当前不可用，使用本地调用关系、差异审读和测试覆盖替代。
